# 思维刻度 · 成人认知自测研究版

免费使用的中文成人认知任务系统。**未标准化、未建立年龄常模；不提供 IQ、百分位、诊断或甄选结果。**

- 768 个不同呈现的原创题库变式，六个任务领域。
- 正式测试 144 题：每领域 24 题，四个设计层级各 6 题；总上限 120 分钟，可提前提交。
- 练习 24 题、20 分钟，不计入正式平均。
- 服务端随机组卷、截止时间、评分、进度持久化；优先抽取未做题，报告重复数。
- 化名注册、在线登录、恢复码找回；多次测试、总平均及最近最多三次平均。
- 私有记录导出为真实 Excel .xlsx（汇总/记录/说明），凭证不导出。

## 科学限制

CHC/现代多领域测量思想启发任务覆盖，但本题库未经过信度、因子结构、效度、跨设备公平性、IRT 校准或试卷等值验证。设计层级不是经验证的难度。固定配额并不保证随机试卷等值。没有中国成人年龄常模，不能给 51 岁用户作虚构年龄补偿。注意任务按准确率而非反应速度评分。开放、无人监考与开源的系统不能防止外部工具或查看规则。重测平均仅是任务成绩平均，练习与疲劳可能影响它。

下一阶段需研究方案、必要伦理审查、有代表性中文成人样本、项目质量分析、可靠性与结构验证、外部效度与随机试卷等值；不得直接以自选访客样本建立中国人口常模。

## 架构

GitHub Pages 作为公开入口，完整系统在具备服务端与持久数据库的托管站点运行。单纯 GitHub Pages 无法执行注册、数据库访问与可信计时。注册不要求 ChatGPT 账户。后端采用 Vinext/Cloudflare Worker + D1，凭证从环境绑定读取，绝不放进 GitHub。

用户名 AES-GCM 加密，规范化查找索引 HMAC；密码 scrypt N=32768,r=8,p=3，每账号独立随机盐；恢复码 SHA-256 摘要；随机会话的摘要保存在库里，原令牌在 Secure、HttpOnly、SameSite=Strict Cookie。来源校验、频率限制、用户所有权检查、乐观并发控制。保护是应用级控制，不声称达到经外部审计的认证服务标准。

必须配置环境变量 `COGNITION_KEY`（64 位十六进制密钥）；需要 D1 绑定 `DB`，迁移保存在 drizzle/。密钥丢失会导致用户名密文不可解密。不能公开数据库、会话令牌或运行时密钥。

源码：app/api/*；lib/engine.mjs；lib/bank.json；public/cognition.html；scripts/generate-bank.py。
题目答案只由后端在测试结束后发送；开源源码仍含规则与答案，因此本系统适合自我观察和练习，不适合高风险或防作弊测量。

## 验证

`node tests/engine.test.mjs`：真实 SQLite 运行数据库逻辑，覆盖分层组卷、计时、评分、账户隔离、记忆呈现时序、并发版本、超时、练习排除、平均值与恢复。
生成的测试 Excel 可用 openpyxl 打开检查。本地测试仅使用合成账户与内存数据库，不接触用户记录。

生成题库：`python scripts/generate-bank.py`。
项目遵循 Sites 构建/迁移/发布流程。

## 分数定义

总分＝六领域正确率等权平均，内部先用未四舍五入的比例算总分，显示保留两位小数。错答与未答均计错，无猜测校正。正式测试可提前提交；提前提交及超时均纳入平均。当前版本已结束正式测试按开始时间倒序取最近最多三次；少于三次使用实际次数。不同题库版本不混入当前平均。
